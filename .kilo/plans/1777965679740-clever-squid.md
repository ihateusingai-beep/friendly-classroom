# 友愛教室 - 架構檢視報告

## 1. 專案概況

**專案名稱**: 友愛教室 - 像素大冒險
**類型**: 單頁 HTML 互動式教育遊戲
**用途**: 透過情境選擇教授國小學生友誼與人際相處技巧

---

## 2. 技術架構

### 2.1 技術棧
| 層面 | 技術 |
|------|------|
| 前端框架 | 純 HTML + CSS + JavaScript (無框架) |
| 樣式 | 像素風格 CSS (CSS Variables, @keyframes) |
| 字體 | Google Fonts (Press Start 2P, Noto Sans HK) |
| 音頻 | Web Audio API (程式生成音效) |
| 語音 | Web Speech API (TTS) |
| 存儲 | localStorage |

### 2.2 專案結構
```
/friendly-classroom
├── index.html       # 主頁面 (3246 行，all-in-one HTML)
├── scenarios.json  # 情境數據 (未實際使用，JS 已內置)
└── assets/         # 靜態資源 (SVG 角色圖)
    ├── 小傑.svg
    ├── 小美.svg
    └── 老師.svg
```

│  │  State   │ │ Scenario │ │ Options  │ │ Effects  │   │
│  │ Manager  │ │  System  │ │  System  │ │  System  │   │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘   │
├─────────────────────────────────────────────────────────┤

│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐   │
│  │  Skills  │ │  Badges  │ │Concepts  │ │  Stats   │   │
│  │ (6 types)│ │ (16 pcs) │ │ (8 cards)│ │  Track   │   │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘   │
├─────────────────────────────────────────────────────────┤
│                   Sub-Systems                           │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐   │
│  │   TTS    │ │  Audio   │ │ Settings │ │  Admin   │   │

### 3.2 數據模型

**Scenarios** (內置於 JS)
- `id`: 唯一識別
- `title/background/description/hint`: 內容
- `characters[]`: name, emoji, initial_relationship
- `options[]`: id, text, effects[], next_scenario
- `location`: classroom | break | home

**Relationships** (localStorage)
```
{ "小傑": 55, "小宇": 70, "老師": 50, ... }
```

**GameStats** (localStorage)
```javascript
{
  gamesPlayed: 0,
  totalScore: 0,
  bestScore: 0,
  currentStreak: 0,
  bestStreak: 0,
  perfectGames: 0,
  badges: [],
  skills: { empathy: 0, respect: 0, courage: 0, 
            honesty: 0, kindness: 0, communication: 0 },
  unlockedConcepts: []
}
```

**Settings** (localStorage)
```javascript
{ fontSize: 20, speechRate: 0.9, soundEnabled: true, playerName: '' }
```

## 6. 觀察

### 6.1 優點
1. **無依賴**: 純前端，無需後端或框架
2. **便攜性**: 單一 HTML 檔案，易於部署
3. **離線支援**: 所有資源內置
4. **無障礙**: TTS、減少動畫支援
5. **音效節省**: Web Audio API 免音頻文件

### 6.2 潛在問題
1. **過度耦合**: HTML/CSS/JS 全在同一檔案
2. **代碼重複**: 多處相似邏輯 (如 badge check)
3. **scenarios.json 未使用**: 有外部檔案但代碼內置
4. **錯誤處理不足**: 缺少 try-catch 和用戶友好的錯誤提示
5. **類型安全**: 純 JS 無編譯時檢查

### 6.3 擴展性限制
1. 新增關卡需改 JS 程式碼
2. 無法動態載入外部情境
3. 難以支援多人或教師模式

## 8. 總結

此專案為**完整的單頁 HTML 教育遊戲**，具有精緻的像素風格 UI、完善的技能/徽章系統、良好的無障礙支援。缺點主要在於代碼組織方式（all-in-one）與擴展性限制，適合小規模獨立專案但不利於大型維護。
